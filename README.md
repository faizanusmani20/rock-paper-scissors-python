# Rock Paper Scissors (Python)

A simple command-line Rock Paper Scissors game built with Python.

## Features

* Play Rock Paper Scissors against the computer
* Random computer choices using Python's `random` module
* Input validation
* Score tracking for player and computer
* Match continues until the player decides to quit
* Beginner-friendly Python project

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/rock-paper-scissors-python.git
```

2. Navigate to the project folder:

```bash
cd rock-paper-scissors-python
```

3. Run the program:

```bash
python main.py
```

## Controls

* `r` = Rock
* `p` = Paper
* `s` = Scissors
